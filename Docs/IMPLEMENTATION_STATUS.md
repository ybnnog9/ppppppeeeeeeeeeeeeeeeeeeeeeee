# Estado actual (Unity)

## Listo
- Scaffold de proyecto Unity en `UnityProject/`.
- Dependencias configuradas en `Packages/manifest.json`.
- Gameplay base y UI en C# (core, score, schedule, modifiers, HUD).
- Generador de escena completa desde menú editor (`MinuteMayhem > Build COMPLETE Unity Setup`).

## Qué puedes personalizar ya mismo
- Colores/materiales en `Assets/MinuteMayhem/Materials`.
- Tamaño y layout del mapa generado.
- Duración de match y orden de modifiers en `MMGameManager`.
- UI de HUD en `MMHud` (o reemplazar por TMP/animaciones).
